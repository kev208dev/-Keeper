# 시연 촬영 순서

## 촬영 전 5분 점검

```bash
./scripts/start-demo.sh
./scripts/reset-demo.sh
./scripts/check-demo.sh
```

스마트폰에서 점주 앱에 로그인하고, 태블릿 개발자 설정에서 MacBook Wi-Fi 주소·기기 키 연결 테스트를 마칩니다. Supertonic 모델 준비 완료 문구와 카메라 영상 파일을 미리 확인합니다.

## A. CCTV 확인 필요 이벤트

1. 시뮬레이터에서 영상 파일을 카메라에 등록하거나 `docs/CCTV_TEST.md`의 분석 명령을 실행합니다.
2. 자동 시나리오 또는 수동 `다음 단계`로 이동 이벤트를 보냅니다.
3. 점주 스마트폰 알림에서 `AI 분석 · 확인 필요`, 확률, 판정 근거를 보여 줍니다.
4. 알림 상세에서 실제 클립을 재생·일시정지합니다.
5. 점주가 확인 처리를 누릅니다.

멘트: “POS 데이터가 없으므로 절도나 미결제로 단정하지 않고, 점주가 확인할 영상 근거를 제공합니다.”

## B. 고객 문의와 답변

1. Android 키오스크에서 `점주에게 도움 요청`을 누릅니다.
2. 유형과 내용을 입력해 보냅니다.
3. 점주 앱 문의 목록에서 같은 내용을 엽니다.
4. 점주가 실제 답변을 입력합니다.
5. 최대 5초 안에 태블릿 답변 화면이 나타나는지 확인합니다.
6. `답변 음성으로 듣기`로 Supertonic 한국어 음성을 재생합니다.

웹 시뮬레이터는 `web-simulator`, 태블릿은 고유 UUID로 소비자가 분리되어 태블릿 대상 답변을 먼저 가져가지 않습니다. 답변 화면 렌더링 뒤에만 전달 완료됩니다.

## C. 카메라 연결 상태

1. 시뮬레이터에서 카메라 `connected`를 보냅니다.
2. 점주 앱 CCTV 화면의 정상 상태를 보여 줍니다.
3. 수동 단계로 `disconnected`를 보내 연결 이상을 확인합니다.
4. `connected` 복구 이벤트를 보내 정상 상태 복귀를 보여 줍니다.

## 촬영 제어

- 자동 실행: 이벤트 간격을 설정하고 전체 시나리오 시작
- 멈춤: 현재 단계 뒤 실행 중지
- 수동: `수동 시나리오 준비` 후 원하는 순간마다 `다음 단계`
- 재촬영: `./scripts/reset-demo.sh` 후 시나리오 재시작

실패 시 `.demo/server.log`, `./scripts/check-demo.sh`, Android 개발자 설정의 연결 테스트 순서로 확인합니다.
